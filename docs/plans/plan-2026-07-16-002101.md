# Build "Prompt Vault" — All Prompts Library View

## Key Decisions

- First real frontend screen: the "All Prompts" library view (sidebar + top bar + card grid), matching a screenshot the user provided. Branded "Prompt Vault".
- Scope limited to this one view. Collections/Starred/Archived nav destinations, create-prompt flow, edit-prompt flow, and filter/sort logic are visually present but inert (TODO) — not built in this pass.
- Wired to real Supabase data via the existing `GET /api/prompts` route (not mock data).
- New dependency: `lucide-react` for icons (only new dependency; no date library — relative-time formatting is hand-rolled).
- Fonts: wire up `next/font/google` to back the `--font-display` (serif, brand title only) and `--font-mono` (small meta text) CSS variables that `tailwind.config.ts` already references but never defines. Leave `font-body`/Georgia unused since the screenshot's body copy is sans-serif. No new Tailwind color tokens — map to default palette (blue-600/700, gray-200/500/600, blue-50 for active nav pill).
- Search is the only functional interactive element beyond existing sign-out; everything else in the screenshot is visually built but non-functional this pass.

## File / Component Structure

```
components/
  layout/
    Sidebar.tsx              — brand block, New Prompt button, nav list (All Prompts active; rest inert), footer (settings/help inert, user card + working sign-out)
    TopBar.tsx                — functional search input, static bell/settings icons, New Prompt button
    FloatingActionButton.tsx  — fixed bottom-right sparkle button, onClick is TODO no-op
  prompts/
    PromptCard.tsx            — single prompt: title, inert 3-dot menu, clamped content, TagPills, divider, last-edited + inert Edit link
    CreatePromptCard.tsx      — dashed CTA tile in the grid, shares the New Prompt handler
    TagPill.tsx                — single tag pill, style chosen by index % 3 rotation
lib/
  format-date.ts              — formatLastEdited(isoDate): "Xm/Xh/Xd ago" then falls back to "Mon D, YYYY"
  hooks/
    usePrompts.ts             — client hook: debounced search, auth token via supabase.auth.getSession(), fetches GET /api/prompts
app/
  page.tsx                    — replaces the stub homepage; composes Sidebar/TopBar/grid/FAB, owns search state, loading/error/empty states
  layout.tsx                  — adds next/font (display + mono), updates metadata.title to "Prompt Vault"
package.json                 — add lucide-react
```

## Implementation Order

1. Add `lucide-react` dependency.
2. Wire fonts + title in `app/layout.tsx`.
3. Build `lib/format-date.ts` and `lib/hooks/usePrompts.ts`.
4. Build `components/prompts/TagPill.tsx`, `PromptCard.tsx`, `CreatePromptCard.tsx`.
5. Build `components/layout/Sidebar.tsx`, `TopBar.tsx`, `FloatingActionButton.tsx`.
6. Replace `app/page.tsx` with the composed library view wired to real data.
7. Manual verification: dev server, auth flow, real data rendering, search, responsive layout, inert elements don't crash.
